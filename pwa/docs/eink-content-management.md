# E-ink 内容编排（PWA）

PWA 的设置页提供 E-ink 内容的显示模式、内容选择和本地预览。编排偏好保存在浏览器的 `guozi-eink-arrangement`，不会写入后端数据库，也不会声称已经下发到设备。

## 已接入的只读语义

- PWA 读取既有 `GET /api/eink/state`，复用日程、待办、未读信件数和设备状态。
- 请求带上上一次响应的 `ETag`；后端返回 `304` 时，PWA 保留上一份预览并显示“内容未变化 · 设备无需重刷”。
- 新的 `revision` 会替换预览，并在页面上显示，便于核对当前状态。
- 网络离线或 E-ink/ESP32 离线时，PWA 保留最近一次预览并明确提示“暂不可达”；不会伪造实时设备读数或已下发状态。

显示配置的服务端写入接口尚未存在，因此本页面当前是“本机编排 + 后端状态预览”。如未来增加配置写入接口，应在不改变当前 ETag/revision 读取语义的前提下接入，并单独补充下发确认状态。

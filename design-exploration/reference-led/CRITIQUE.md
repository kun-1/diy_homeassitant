# Reference-led concept critique

## Impeccable synthesis

The first reference-led concept was polished but read as an AI-generated dashboard: too many equal-weight cards, generic device tiles, decorative hardware renders, a fake phone frame, and invented or contradictory states.

The two independent reviews agreed on five corrections:

1. Give every screen one dominant state or metric.
2. Make the household loop visible: issue → action → physical result or resolved state.
3. Remove phone hardware, device photography, decorative icon circles, and nested cards.
4. Use only coherent, grounded states; never imply unsupported sensor readings or timestamps.
5. Translate the reference through black/white contrast, generous negative space, one accent, and one purposeful geometric motif.

The browser detector portion of Impeccable was not applicable because the target was a generated PNG rather than a live HTML/CSS surface.

## Regeneration brief

`ios-family-control-concept-v2.png` uses two flat app canvases:

- Overview: `1 项需要处理` → `打印机 · 等待连接` → `查看`
- Device detail: `等待连接` → `重新连接` → `查看打印任务`

The screens intentionally preserve the native iOS information architecture while reducing the visual language to ink, paper, and one coral-orange signal. Ghost is reduced to a small state-aware mark rather than a mascot or decorative illustration.

## Remaining caveat

Image generation can still introduce small typography or spacing inaccuracies. This image is a direction-setting artifact; the final iOS implementation should use real SwiftUI typography, SF Symbols, Dynamic Type, native navigation, and data supplied by the backend.
